# 3D Fighters - Browser Fighting Game

A browser-based 3D fighting game inspired by Tekken, built with Three.js.

## Features
🎮 Full 3D fighting arena  
👥 6+ playable characters  
⌨️ Keyboard & gamepad controls  
🌐 Works in any modern browser  
📱 Responsive design  

## Quick Start

```bash
# Clone repository
git clone https://github.com/chefentangermark/3d-fighters-browser.git
cd 3d-fighters-browser

# Run locally
python -m http.server 8000
# Visit http://localhost:8000
